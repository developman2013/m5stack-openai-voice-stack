Install M5Stack Voice Firmware

Connect an M5Stack Atom Echo to this computer with a USB data cable, then install the firmware.

Use Chrome or Edge on a desktop computer. The browser needs permission to access the USB serial device.

Configure over USB

After flashing, keep the USB cable connected and configure the device here. This avoids connecting your phone to the device setup Wi-Fi.






  
Web Serial requires Chrome or Edge on a computer. If USB configuration is unavailable, the device still provides its setup Wi-Fi portal.
