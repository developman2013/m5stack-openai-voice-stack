M5Stack Voice setup

Два шага: установите прошивку, затем настройте устройство через USB.

1. Установить прошивку

Подключите M5Stack кабелем USB с передачей данных.

2. Настроить устройство

Оставьте M5Stack подключённым по USB. Перед сохранением будут проверены Wi‑Fi, gateway и token.

Сначала подключите последовательный порт.
